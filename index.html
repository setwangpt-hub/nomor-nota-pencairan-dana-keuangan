Sambungan Google Sheets

Tempel URL Web App Apps Script (berakhiran /exec) dari spreadsheet Register Nomor Nota Dinas. Petunjuknya ada di README repositori.

Aturan penomoran

  1. Nomor NPD melanjutkan nomor terakhir di sheet NPD 2026, format 000/KPA/KEU/2026.
  2. Nomor dihitung ulang dari sheet tepat sebelum disimpan, jadi isian lewat Google Form tetap berurutan.
  3. Tanggal NPD otomatis tanggal hari ini; sub kegiatan dan kode rekening mengikuti nodin yang dipanggil.

Nodin baru dari aplikasi

Nomor nodin yang diambil di aplikasi Nomor Nodin setelah 3 November tersimpan di browser aplikasi itu. Muat file cadangannya (.json, tombol "Unduh cadangan data" di tab Arsip) agar nomor itu bisa dipanggil di sini.
